# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？
リモートリポジトリは、ネット上で共有できるサーバーで、ローカルリポジトリは自分のPC上のサーバーで、他の人は編集できない

## プッシュとマージの違いは何でしょうか？
プッシュはローカルの内容をリモートに反映させ、チームに変更を共有することができ、マージは他のブランチの変更を今いるブランチに取り込むという違いがある。

## コミットとプッシュの違い
コミットは自分のPC内のみに変更を保存でき、プッシュは他の人に変更内容を共有することができる。

## コミットのメッセージはどのように書いてあげるのが最適でしょうか？
変更内容をわかりやすく簡潔に記載し、「”」で囲うことで見やすくすることが最適。

## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？
ローカルでマージは手軽なため一人での作業に向いていて、プルリクエストでのマージは、少し手間がかかるがチームで安心して作業ができるという違いがある。

## コンフリクトを起こしてしまった場合、どう対処すべきですか？
方法は主に３つあり、先にマージされた変更内容を取り込むか、後にマージしようとしている変更内容を取り込む、どちらの変更内容も取り込むのいずれかの方法で対処できる。
